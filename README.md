## 📂 Repository Structure
- `iterative_sprints/`: Day 1 to Day 10 modular physics and AI simulations.
- `docs/`: IEEE copyright notices and paper access information.

## 🚀 Quick Start
```bash
pip install -r requirements.txt
cd iterative_sprints/day_01
python day_01_script.py
```
